# Antigravity Execution & Context Governance (Agy-Context-Saver + RTK)

## Layer 1: Background Tasks & Proportional Backoff
- **Reactive Wakeup (no busy-polling)**: Never poll `manage_task(Action='status')` in loops or schedule short/unconditioned task timers; yield and wait for `<SYSTEM_MESSAGE>`.
- **Remote CI / PR checks**: Never run blocking CLI watches (`gh pr checks --watch`, `gh run watch`) inside `run_command`; run one-shot snapshots (`gh pr checks`, `gh run list`) and, if waiting on remote CI/PR builds/deployments, arm a backoff-compliant `schedule` timer (`>= 30s`, scaling `30s -> 75s -> 188s -> 469s -> 600s`; `15..required-1` auto-clamps; no local `task-X` `TimerCondition` required).
- **Per-task exponential backoff**: Tracked per task (`0s -> 30s -> 75s -> 188s -> 469s -> 600s`, pruned on completion). Check #1 (`0s`) is allowed **before** arming a `schedule` watchdog; afterward, `manage_task(Action='status')` waits for the watchdog cooldown. Reading raw `.system_generated/tasks/*.log` while `RUNNING` is always denied (`manage_task(Action='kill')` and `send_input` are always allowed at `0s`). 5 cumulative denials trip `force_ask`.
- **Conditioned stall watchdogs (`schedule`)**:
  - When a `run_command` moves to the background, arm `schedule(DurationSeconds=45, Prompt="Check status of background task-X", TimerCondition="<convId>/task-X")` (auto-cancels at zero cost on completion; `>= 15s` auto-clamps; `< 15s` or unconditioned task polls are denied) and output a brief Pre-Yield Status Card (Command, Scope, Estimated Duration, Watchdog).
  - Never pair `/swarm` (`swarm_wait`) with a one-shot `schedule` timer (`swarm_monitor` handles stalls). Direct `invoke_subagent` runs may optionally arm a conditioned stall watchdog (`TimerCondition="<subagentConvId>"`, `180s -> 450s -> 600s`; `30..179s` auto-clamps).

## Layer 2: Shell Pre-Gate, File Bounds & Transcript Governance
- **Narrow High-ROI RTK Pre-Gate (`>= 1.1.0`)**: Delegates noisy runners (`pytest`, `python -m pytest`/`mypy`, `uv run pytest`/`ruff`/`mypy`/`ty`, `cargo`, `go`, `vitest`, `jest`, `tsc`, `eslint`, `ruff`, `npm`/`pnpm`/`bun` noisy `run` scripts & `lint`, `docker build`/`ps`/`logs`/`compose ps|logs|build`, `kubectl get`/`logs`/`describe`/`apply`, `git status`/`push`/`pull`/`fetch`) via `rtk hook antigravity` (`AGY_RTK_MODE=pregate|off|all`, default `pregate`; explicit `rtk <cmd>` always works). Precision tools (`find`, `grep`, `rg`, `ls`, `wc`, `diff`, `ps`, `git diff`/`show`/`log`, workspace `cat`/`head`/`tail`), pipes, stdout/file redirects, and machine-readable flags (`--json`, `--porcelain`, `git status -sb`, `-o json`, etc.) stay untouched and lossless (`2>&1` / `2>/dev/null` pass through).
- **Workspace discovery & `read_file` bounds**: Native `grep_search`, `find_by_name`, and `list_dir` work on workspace paths (blocked on `.system_generated/`, `getStateDir()`, and protected brain roots). On `read_file`:
  - Files `<= 300` lines and `<= 24 KiB`, safe media (`.png`, `.jpg`, `.webp`, `.pdf`, audio/video), and special files (`SKILL.md`, `AGENTS.md`, own brain artifacts, `swarm_view/`, `.gemini/config/`) need no line bounds.
  - Larger files accept slices up to `300` lines (`StartLine`/`EndLine`, EOF-clamped up to `1 MiB`, single-bound supported) or explicit full-file audits (`StartLine: 1, EndLine >= TotalLines`) when `<= 800` lines and `<= 45 KiB`. `read_many_files` and `ByteOffset`-only reads are denied.
- **Spillovers & completed task logs**: Both `.system_generated/steps/<step>/output.txt` and `COMPLETED` `tasks/<taskId>.log` accept bounded `read_file` (`<= 150` lines) or single unchained `rtk read <path>` (`cat`/`head -n 150`/`tail -n 150` auto-rewrite to `rtk read`; `--head-lines 150` / `--tail-lines 150` required above `45 KiB`).
- **Transcript forensics & access control**: Direct access to `.system_generated/` or `getStateDir()` is blocked across all brain roots. Use single unchained `agy-context transcript <read|query|step|health|list|export|access>` (`--sanitized` required on `export`; see the `context-governance` skill or `agy-context transcript --help` for full flags). Parents scope children via `agy-context transcript access` or line-1 `[agy-transcript-access: deny|self-only|allow]` launch directives (Precedence: `Owner -> --deny -> --allow (@roster*) -> Launch Directive -> Cohort Default`). Restricted children must not retry blocked transcript commands (5 denials trip `force_ask`).
- **Git line endings**: Suppress CRLF/LF notices with `git -c core.safecrlf=false`.

## Layer 3: Synchronous Execution & Benchmark Integrity
- **10s synchronous window**: Non-daemon `run_command` calls default to `WaitMsBeforeAsync: 10000` when omitted.
- **Targeted tests**: Prefer targeted test files/directories (`-x`/`--maxfail=1` while debugging) and arm a conditioned `schedule` watchdog for long sweeps.
- **Benchmark guard**: Edits to `benchmarks/`, `evaluation/`, `evaluators/`, `scoring/`, `ground_truth/`, or `prompt_templates/` prompt via `force_ask` (set `AGY_DISABLE_BENCHMARK_GUARD=1` in non-evaluation repos for top-level non-restricted sessions).
