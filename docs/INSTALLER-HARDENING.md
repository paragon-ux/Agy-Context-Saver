# Installer hardening policy

This document summarizes the installer safety contracts, runtime self-protection boundaries, and regression verification suites in `Agy-Context-Saver`.

## Enforced behavior before any user-profile write

`runInstall()` in `scripts/install-register.mjs` and the Windows wrapper `install.ps1` run a preflight phase before mutating any user configuration:

1. **Read-only configuration validation (`parseAndValidateJsonConfig`)**: The installer parses existing `hooks.json`, `config.json`, and `mcp_config.json` files and verifies that each is a non-null JSON object (`mcpServers`, if present, must also be a JSON object) **before** `--check` returns or any disk writes occur. Malformed or non-object JSON aborts installation immediately and leaves the user's original file bytes unchanged.
2. **Strict read-only `--check` and `--status`**: Passing `--check` (`-c`), `--status`, or `--help` creates zero files or directories and makes zero network calls. Conflicting flags (`--check --restore-backups` or `--check --uninstall`) exit with a non-zero status code. `agy-context status` (`runStatus()`) reports all active integration layers.
3. **RTK `>= 1.1.0` and SHA-256 supply-chain verification**: `findExistingRtk()` validates that any local or `PATH` RTK binary satisfies `>= 1.1.0`. Automated archive downloads fail closed unless pinned `RTK_CHECKSUMS` match before extraction.
4. **Fail-closed provisioning and MCP retirement**: If RTK provisioning fails, installation aborts before touching `hooks.json`, `mcp_config.json`, plugin links, or CLI shims (unless `--allow-degraded` is passed). On setup and uninstall, the installer prunes legacy `agy-context-saver*` keys and schema directories while leaving foreign MCP servers untouched.
5. **Single global hook surface & Windows `node.cmd` retirement**: `agy-context setup` registers a single `PreToolUse` hook entry in `~/.gemini/config/hooks.json` pointing directly into `~/.gemini/config/plugins/agy-context-saver/scripts/execution-guard-hook.mjs` (plugin `hooks.json` is `{}` and no standalone `~/.gemini/config/scripts/execution-guard-hook.mjs` mirror is created). On Windows, `scripts/install-register.mjs` and `install.ps1` invoke `node` directly and no longer create a managed `~/.gemini/config/node.cmd` wrapper; both `setup` and `uninstall` automatically remove any legacy `~/.gemini/config/scripts/execution-guard-hook.mjs` mirror and any legacy managed `node.cmd` wrapper (`agy-context-saver-managed`), restoring `node.cmd.bak` if present.
6. **Namespaced, non-clobbering backup restore & post-uninstall reload notice**: Hook and MCP backups are namespaced (`hooks.json.agy-context-saver.bak` and `mcp_config.json.agy-context-saver.bak`), validated as JSON objects before restore, and key-merge restored so third-party plugins' hooks and MCP servers are never clobbered. `agy-context uninstall` prints an explicit reload notice instructing users to reload Antigravity Desktop IDE or start a new session so cached in-memory `PreToolUse` hook registrations clear cleanly.
7. **User config & governance file protection**: During active runs, `scripts/execution-guard-hook.mjs` (via `scripts/hook/file-guard.mjs` and `scripts/hook/shell-guard.mjs`) asks the user to confirm (`force_ask`) edits to non-symlink `~/.gemini/{config,antigravity*}/{mcp_config.json,config.json}` from top-level sessions (not a child, not under a restrictive transcript policy), and hard-denies those edits for child sessions (subagents and `/swarm` workers). Global `~/.gemini/config/hooks.json`, `*.bak` backups, `~/.gemini/config/plugins/agy-context-saver/` (plugin and hook source), symlinks, and destructive shell verbs (`rm`, `mv`, `ln`, `truncate`, `shred`, `dd`, `chmod`, `chown`, `find`) are hard-denied for every session. Lifecycle commands (`setup`, `uninstall`, `restore-backups`) are not blocked.

## Regression test coverage

The automated test suite (`npm test`) verifies these contracts across isolated `AGY_TEST_PROFILE_DIR` sandboxes:

- `tests/test-check-only-readonly.mjs`: Verifies `--check` on a clean temporary home leaves the profile and source tree untouched, fails closed on malformed existing config without writing, and rejects conflicting `--check --restore-backups` flags.
- `tests/test-malformed-config-preservation.mjs`: Verifies malformed `hooks.json` and non-object JSON shapes abort installation before modifying `hooks.json` or `mcp_config.json`.
- `tests/test-lifecycle-rollback.mjs`: Verifies foreign hook and MCP preservation, namespaced non-clobbering backup creation and key-merge restoration, legacy mirror and Windows `node.cmd` cleanup, post-uninstall reload guidance, upgrade idempotency, incompatible `PATH` RTK rejection, and symlink or junction fallback to directory copy.
- `tests/test-hook.mjs`: Verifies that hard-denied paths (installed plugin hooks, state files, governance scripts, global `hooks.json`) cannot be mutated, and that user config edits prompt top-level sessions and are denied for child sessions.
