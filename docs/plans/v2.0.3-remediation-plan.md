## 0. Non-Regression Guardrails (`L32`–`L50`) & Scope Split

Before modifying hook, CLI, or installer code, all workstreams must preserve these invariants:

1. **Application-Layer Security & Brain Containment (`L32`, `L38`, `L39`, `L40`):**
   - Keep `verifyTranscriptCoreAccess()` single-use, operation-bound (`read`, `query`, `step`, `health`, `list`, `export`), and consumed synchronously before async I/O.
   - Preserve `<brainDir>` / `<brainDir>/<callerConvId>` containment on both `--id` and `--file`, 5-tier access precedence, `<stateDir>` protection, and 5-strike `force_ask` circuit breakers documented in [Governance](../governance.md).
2. **`/swarm` Lineage, Safe Harbor & Blocking-Watch Isolation (`L45`, `L50`):**
   - Preserve Step 0..47 `sender=` parent binding (`inspectTranscriptLineageFromFile`), `parent:<uuid>` / `multi:` capability grants, `swarm_view/` narrator Safe Harbor, `env-cache.json` (`60s` TTL + binary mtime) invalidation, and blocking `gh pr checks --watch` / `gh run watch` + `isSwarmPollSchedule` protections.
3. **Cross-Platform Parity & Zero-Dependency Boundary (`L46`, `L49`, `L50`):**
   - Maintain zero runtime npm dependencies across `lib/`, `bin/`, and `scripts/`, `resolveProfilePaths()` dynamic profile isolation (`AGY_TEST_PROFILE_DIR`), `chcp 65001 >nul` Windows `.cmd` shims, fail-closed `install.ps1` Node lookup, strict `bin/agy-context.mjs` `parseFlags`, `release-preflight.mjs` metadata + README test-suite parity, and `tests/verify-package.mjs` boundary rules.
4. **Two-Repo PR Separation (`L26`, `L31`):**
   - `W1`–`W4` (`10` `Agy-Context-Saver`-scoped items) land in `paragon-ux/Agy-Context-Saver`.
   - `W1`–`W7` (`130` `Agy-Squad`-scoped items) land separately in `paragon-ux/Agy-Squad`. Both installers coordinate shared naming for `S2-DEP-001` (`mcp_config.json.<plugin>.bak`) and dangling-symlink `unlink` safety (`S2-SCRIPT-011`).

## 2. W1 — `PreToolUse` Hook Scoping & RTK Clamping Guards

### Scope & Covered IDs (`2` P2 items)
- `LEAD-DEP-001`, `ACS-HOOK-GREP-CLAMP`

### Concrete Implementation Design
1. **Scope `mcp/index.js` Probe Guard Strictly to `Agy-Context-Saver` (`LEAD-DEP-001`, `scripts/execution-guard-hook.mjs:230-236`):**
   - `isProtectedShellOrScriptOperation` currently blocks inline interpreters/scripts matching `\bmcp[\/\\]+index\.js\b` (`#L231`), which falsely blocks diagnostic probes importing companion `Agy-Squad/mcp/index.js` even though `Agy-Context-Saver` v2.x retired its own `mcp/` directory (`release-preflight.mjs` forbids `mcp/` at root).
   - Remove the stale unqualified `\bmcp[\/\\]+index\.js\b` clause or narrow it strictly to retired `Agy-Context-Saver` paths (never matching `Agy-Squad/mcp/index.js` or sibling plugins), preserving full protection on `transcript-core.mjs` and `bin/agy-context.mjs`.
   - Sync exception behavior cleanly if needed in [CLI & Hook Reference](../tools.md) and `tests/test-hook.mjs`.
2. **Prevent Silent `rtk grep` / Spillover Clamping Losses (`ACS-HOOK-GREP-CLAMP`, `scripts/execution-guard-hook.mjs:3723-3729, 4368-4382`, `rules/AGENTS.md`):**
   - Extend `ACS-HOOK-09` lossy-command handling (`subcmd === "wc" || subcmd === "ls" || subcmd === "diff"` at `#L3724`) so `grep` searches needing untruncated lines or `>25` matches per file are not silently lossy-truncated by `rtk grep` (~`80`-char line clip + ephemeral `rtk recall` hashes unreadable in static transcripts) — either revert implicit `grep` rewrites alongside `wc`/`ls`/`diff` or require explicit opt-in / lossless flag passthrough and document exact `rtk recall` vs lossless search usage in `rules/AGENTS.md` and `skills/context-governance/SKILL.md`.
   - On `isRtkRead && (isSpillover || taskMatch)` (`#L4368-L4382`), retain the `> 46080` byte blowout protection while ensuring callers are never silently surprised that `#L4377` rewrote an unbounded read into `--tail-lines 150` (emit explicit guidance or clean notice/flag handling for `--head-lines` vs `--tail-lines`).

## 3. W2 — Transcript Core Preview Density & Window Headroom

### Scope & Covered IDs (`1` P2 item)
- `ACS-RUN-TRANSCRIPT-CLAMP`

### Concrete Implementation Design (`lib/transcript-core.mjs`)
1. **Strip Boilerplate Before `queryTranscript` Summary Slicing (`#L2554`):**
   - In `queryTranscript`, strip leading Antigravity step metadata boilerplate (`Created At: ... Completed At: ...` headers) **before** calling `cleanMessageContent(it.content, 120, { truncationStyle: "ellipsis" })`, reclaiming ~`88`+ characters of actual step/stdout signal per summary line without increasing line count or violating the `24 KB` (`MAX_OUTPUT_CHARS`) safety ceiling.
2. **Widen Compact Tool Argument & `--mode compact` Windows (`#L1526, #L1795-L1867, #L2187-L2214`):**
   - In `formatCompactToolList` (`#L1526`), widen compact key-arg preview slicing from `36` chars (`slice(0, 33)`) to e.g. `72–96` chars (while keeping `--full-args` lossless) so paths, flags, and query arguments remain identifiable in `--summary` and compact views.
   - In `readTranscript` (`#L1795, #L1830, #L1850`), raise `maxWindowChars` for `mode === "compact"` from `3800` chars to `8000–12000` chars (matching `fullOutput` safety ceiling messaging at `#L1865`) and raise the non-dialogue (`!isDialogueTurn`) step cap from `300` to `800–1000` chars, while verifying `getTranscriptStep` batch clamping (`#L2187-L2214`, `perStepMaxChars` / `MAX_FIELD_CHARS`) retains generous multi-step headroom under `24 KB`.
   - Goal: let `--last-turns 10` and `query --summary` answer normal Integrity Auditor checks in `1–3` calls instead of `29–30` fragmented follow-up calls.

## 4. W3 — Installer Parity, Status Silence & Path Safety

### Scope & Covered IDs (`7` items: `3` P2, `4` P3)
- **P2 (`3`):** `S2-SCRIPT-005`, `S2-SCRIPT-006`, `S2-DEP-001` (`Agy-Context-Saver` half; `Agy-Squad` half in `Agy-Squad` `W6`)
- **P3 (`4`):** `S2-SCRIPT-011` (`Agy-Context-Saver` half; `Agy-Squad` half in `Agy-Squad` `W6`), `S2-SCRIPT-012`, `S2-DEP-004`, `S2-DEP-006`

### Concrete Implementation Design (`scripts/install-register.mjs`)
1. **Broken Symlink Detection & Cleanup (`S2-SCRIPT-005`, `S2-SCRIPT-011`):**
   - In `detectExistingInstallation()` (`#L209-L214, #L303-L311`), compute `pluginLst = fs.lstatSync(pluginDest)` consistently with `pluginExists`: treat a broken `pluginDest` symlink as `BROKEN SYMLINK` (`pluginExists || Boolean(pluginLst)` in `isInstalled`) so `status` reports `PARTIAL INSTALLATION` rather than `NOT INSTALLED`, matching `Agy-Squad`.
   - In `runUninstall()` (`#L787, #L834`), probe `destHook` (`#L787`) and CLI `shimPath` (`#L834`) via `fs.lstatSync` before `fsPromises.unlink`, ensuring dangling symlinks are cleanly removed.
2. **Fail-Closed Pre-Validation in `runUninstall()` (`S2-SCRIPT-006`, `#L769-L825`):**
   - Parse and validate `hooksJsonPath`, `configJsonPath`, and `mcpJsonPath` **before** removing `pluginDest` (`#L769-L784`) or `destHook` (`#L787-L794`), and stop swallowing malformed JSON errors silently inside `catch {}` (`#L806, #L816, #L824`). Mirror the fail-closed pre-validation guarantees already enforced in `runInstall()`.
3. **Namespaced MCP Config Backup (`S2-DEP-001`, `#L44`, `#L887-L918`):**
   - Change `mcpBakPath` in `resolveProfilePaths()` (`#L44`) from shared `~/.gemini/config/mcp_config.json.bak` to `~/.gemini/config/mcp_config.json.agy-context-saver.bak` so `Agy-Squad` and `Agy-Context-Saver` never overwrite or cross-restore each other's MCP backups. During `runRestoreBackups` / upgrade transitions, fall back read-only to legacy `mcp_config.json.bak` only if the namespaced backup does not exist and restoration is explicitly safe/scoped.
4. **Silent `status --json`, Direct `--json` Flag & Dynamic Profile Paths (`S2-SCRIPT-012`, `S2-DEP-004`, `S2-DEP-006`):**
   - Pass `{ silent: true }` into `findExistingRtk({ silent: true })` inside `detectExistingInstallation()` (`#L300`) when invoked under JSON/silent status checks so stderr stays valid JSON-only.
   - Add `"--json"` to `knownFlags` in direct `scripts/install-register.mjs` (`#L986, #L1017`, and wire JSON output handling cleanly in CLI help/dispatch) to match `bin/agy-context.mjs status --json` and `Agy-Squad`.
   - Deprecate or remove static load-time destructured exports (`#L69-L79, #L966-L976`) in favor of `resolveProfilePaths()` so `AGY_TEST_PROFILE_DIR` mutations remain dynamic across tests.
