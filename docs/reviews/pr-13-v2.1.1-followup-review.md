## 3. Architecture-to-Implementation Trace

`Agy-Context-Saver` exists to **reduce** context waste and agent busy-polling friction via three layers: (1) RTK shell compression, (2) bounded workspace file inspection and `.system_generated/` / `getStateDir()` protection, and (3) per-task stall-watchdog governance with fast CLI transcript forensics.

Tracing `design thesis -> decision -> contract -> implementation -> live host execution` across both PR #13 (`dd63cb0`) and the surrounding `PreToolUse` / CLI stack exposes six systemic friction inversions where governance increases token cost, drops information, or dead-ends compliant agents:

1. **Watchdog & remote-CI `schedule` classifier collisions (`PR13-RUN-001`, `PR13-RUN-003`, `FRIC-RUN-004`):**
   - Contract (`rules/AGENTS.md#L17-L23`, `scripts/execution-guard-hook.mjs#L5524`): Background `run_command` jobs must arm `task-*`-conditioned watchdogs; recurring `IsDaemon: true` crons are distinct from polling loops; remote CI waits (`gh pr checks`) should use backoff-compliant `schedule` timers.
   - Implementation: `isSwarmPollSchedule()` (`#L4900-L4913`) runs before `isTaskPollSchedule()` (`#L6134` vs `#L6205`) and matches `/\b(?:swarm|squad|board)\b/i` without exempting `task-*` `TimerCondition`s (breaking watchdogs in `Agy-Squad` live); `isTaskPollSchedule()` (`#L4878-L4892`) omits the `isDaemon && cron` guard; and `isTaskPollSchedule()` traps remote CI timers (`"check on"`, `"check"` + `"job"`/`"test"`) into demanding an impossible local `TimerCondition="<convId>/task-X"` (`#L6221`).
2. **Rigid `read_file` bounds create high-token bounce loops and block binary media (`FRIC-RUN-001`, `FRIC-RUN-002`, `FRIC-RUN-010`):**
   - Contract: Prevent unbounded multi-thousand-line file dumps while keeping routine inspection low-friction.
   - Implementation (`#L5924-L5999`, `#L5145-L5163`): Workspace images, PDFs, audio, and video have no exemption and are hard-denied with `rtk grep -rnE` instructions (`FRIC-RUN-001`). Small files (`<= 150` lines) still bounce when bounds are omitted, `isExplicitFullFile` (`#L5966-L5970`) requires exact `endLine === metrics.lineCount` (so `1..160` on a 138-line `README.md` bounces!), partial reads near EOF deny on requested span instead of effective span, and `getFileMetrics()` (`#L5153`) reads the entire file into memory via `fs.readFileSync()` *before* checking `bytes > 45 KiB`. Every bounce burns an extra full-context LLM turn (20k-100k input tokens) to save 0 bytes.
3. **Silent lossy RTK rewrites degrade code review and live diagnostics (`FRIC-RUN-003`):**
   - Contract (`ACS-HOOK-09`, `ACS-HOOK-GREP-CLAMP`): Revert implicit RTK rewrites that silently drop lines or emit unreadable ephemeral recall hashes (`wc`, `ls`, `diff`, `grep`).
   - Implementation (`#L4674-L4681`): Live `rtk 1.1.0` probes confirm `git diff` -> `rtk git diff`, `git show` -> `rtk git show`, and `ps aux` -> `rtk ps aux` are *not* reverted, silently truncating diff hunks (`... (4 deletions, 57 additions truncated) ...`) and clipping `ps` command lines with ephemeral `rtk recall` hashes.
4. **Omitted-`--id` CLI commands fail on multi-session hosts even though the hook knows `convId` (`FRIC-SVC-001`):**
   - Contract (`plugin.json#L7-L11`): All three suggested prompts (`agy-context transcript health`, `query`, `read`) omit `--id`.
   - Implementation (`#L3246-L3327`, `#L5670-L5686`, `lib/transcript-core.mjs#L1487-L1505`): `injectSelfId` is wired solely for `self-only` mode, never `open` mode. Because Antigravity passes `conversationId` via hook stdin rather than `GEMINI_CONVERSATION_ID`, any host with two tabs, a `/btw` chat, or a subagent active in the last 5 minutes fails every bare `agy-context transcript` command.
5. **Over-broad shell inspection and cross-segment regex matching trigger false denials (`FRIC-RUN-005`, `FRIC-RUN-006`, `FRIC-RUN-007`, `PR13-RUN-005`, `FRIC-SEC-001`):**
   - Implementation: `hasGovernanceMutationInText()` (`#L5090-L5134`) runs across all segments joined in `inspectableCombined` (`#L5561`), treating read-only `sed -n` and `npm install` paired with read-only inspection of `~/.gemini/config/plugins/agy-context-saver` as mutations; `getInspectableTextForSegment()` (`#L3364-L3532`) skips `git commit -m` prose but not `gh pr/issue/release --body/--title/--notes` or `/tmp/*.md` heredocs; `isProtectedShellOrScriptOperation()` (`#L236-L255`) routes `AGY_TEST_PROFILE_DIR` and inline `transcript-core.mjs` imports to a generic `.system_generated` denial; and `findGoverningPolicyForCaller()` (`#L2591-L2598`) leaks another conversation's `activeOwnerId` policy onto unrelated top-level sessions whose `transcript.jsonl` is unflushed or has a `> 512 KiB` Step 0 line.
6. **Contract mismatches and synchronous hook I/O overhead (`PR13-RUN-002`, `PR13-RUN-004`, `PR13-RUN-006`, `FRIC-RUN-008`):**
   - Implementation: `schedule()` advances `pollCount` `0 -> 2` and blocks immediate Check #1 (policy retained per operator; docs need exact sequencing); `denyRunningTask()` prints bogus `1s remaining` countdowns past cooldown (policy retained per operator; wording/math needs fix); `pruneTaskBackoff()` runs up to 64 synchronous `fs.readFileSync(transcript)` calls (`#L4942-L4952`, `#L903`); and dual-hook registration spawns 2 Node processes per governed tool call with a narrow `500ms` cross-script dedup window and unlocked read-modify-write state updates (`#L48`, `#L54-L84`, `#L5224`).
